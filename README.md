# CSE437 - Used Car Price Prediction

VS Code/Jupyter-ready project using Austin Reese's Craigslist used-car dataset.

## Proposal

- **Dataset:** Austin Reese, *Used Cars Dataset*, Kaggle. Standard release: **426,880 rows × 26 columns**.
- **Problem:** Regression — predict `price` (USD), a continuous target.
- **Questions:**
  1. Which features, especially age, mileage, and manufacturer, drive price most?
  2. Do regional markets show different pricing patterns?
  3. Where does the model fail most: luxury, very old, or high-mileage cars?
