# Data source

Dataset: **Used Cars Dataset (Craigslist)** by Austin Reese.  
Source: https://www.kaggle.com/datasets/austinreese/craigslist-carstrucks-data  
Standard file: `vehicles.csv` - 426,880 rows and 26 columns in the common release.

Run `python src/download_data.py`, or manually place the downloaded `vehicles.csv` in `data/raw/vehicles.csv`. The raw file is excluded from Git because it is large and must remain untouched.
